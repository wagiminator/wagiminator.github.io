C64 Disk Editor

Add and remove files on a Commodore 64 disk image, arrange the directory, add separator lines and save the result. Files are placed the way the 1541 does it: next to the directory track, sector by sector with an interleave. Everything happens in your browser.

Directory

Drag entries to reorder them. Drop program files anywhere to add them.

    Disk map

    One column per track, one cell per sector. Select a cell to find its file.
    • Free
    • BAM and directory
    • Used, not part of a file
    • Files (one color each)

    Free space

    664 blocks free

    Used for new files and for defragmenting. 10 is what the 1541 uses; fast loaders often prefer a smaller value.
