WCH RISC-V Programmer

Flash WCH RISC-V microcontrollers with a WCH-LinkE (or WCH-LinkW/-LinkB) straight from the browser: write BIN and HEX files, erase, unlock and unbrick chips. Supports the CH32V00x, CH32V103, CH32V20x, CH32V30x, CH32X03x, CH32L103 and CH57x/58x/59x.

This browser cannot access USB devices. Open this page in Chrome, Edge or Opera on a desktop computer.

Firmware

    Flashing writes and verifies the firmware. A locked chip is unlocked first, which erases it.

    Setup and link mode

    The WCH-Link must be in RISC-V mode: its blue LED is off. If the blue LED is on, connect it and choose Switch to RISC-V mode, or hold the ModeS button while plugging it in.

    Windows: install the WinUSB driver for the WCH-Link's debug interface (not the serial port) with Zadig, as for rvprog.

    Linux: allow access to the device:

    echo 'SUBSYSTEM=="usb", ATTR{idVendor}=="1a86", ATTR{idProduct}=="8010", MODE="666"' | sudo tee /etc/udev/rules.d/99-WCH-LinkE.rules
echo 'SUBSYSTEM=="usb", ATTR{idVendor}=="1a86", ATTR{idProduct}=="8012", MODE="666"' | sudo tee -a /etc/udev/rules.d/99-WCH-LinkE.rules
sudo udevadm control --reload-rules
