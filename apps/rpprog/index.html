RP2040/RP2350 Programmer

Flash the Raspberry Pi RP2040 and RP2350 (Pico, Pico W, Pico 2 and the many compatible boards) over USB with the bootloader in their boot ROM, as picotool does. Write UF2, BIN and HEX files and verify them, see what is on the chip, erase it, read it out and restart it, without copying files to a drive.

This browser cannot access USB devices. Open this page in Chrome, Edge or Opera on a desktop computer.

Firmware

A multiple of 256 (0x100). 0 for a complete program.

    Put the board into BOOTSEL mode, choose Flash firmware and select the board. The 4 KB sectors that the file uses are erased, written and read back; the rest of the flash stays as it is.

    Chip

    Shows the chip, its revision and flash size and the program on it (name, version, pins). The board stays in BOOTSEL mode.

    Leaves BOOTSEL mode and starts the program in the flash.

    Erase and read the flash

    Erases the whole flash; the board stays in BOOTSEL mode.

    Saves the flash as file, to keep a copy or to flash another board with it.

    BOOTSEL mode

    • With the button: hold BOOTSEL, plug the board in (or press RESET or RUN to GND), then release BOOTSEL. The board shows up as a drive named RPI-RP2 or RP2350.
    • From a running program: programs built with the Pico SDK and USB serial output, Arduino sketches (Earle Philhower's core) and CircuitPython restart into BOOTSEL mode when their serial port is opened at 1200 baud:
    • From a blank chip: a chip with an empty flash starts in BOOTSEL mode by itself.

    The app does not use the drive; it talks to the second USB interface of the boot ROM (PICOBOOT), like picotool. Copying a UF2 file to the drive works as well, of course.

    Driver setup

    Windows: the RP2040 needs the WinUSB driver once: run Zadig with the board in BOOTSEL mode, choose “RP2 Boot (Interface 1)” and install WinUSB. The RP2350 needs nothing.

    Linux: the browser needs access to the USB device: install the udev rules of picotool (60-picotool.rules) or a rule for vendor 2e8a.

    macOS: works without setup.
