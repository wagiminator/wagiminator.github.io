The Debugger button opens a monitor below the screen: stop the C64 at any instruction, step through the code, set breakpoints on addresses, memory reads and writes or raster lines, and look at memory, the stack and the VIC, CIA and SID registers. Its command line understands the usual monitor commands (type help).

The Sprites button shows the sprites on the screen, also those a game reuses further down (multiplexing), collects every sprite image while you play, and browses all 256 sprite slots of a VIC bank. Sprites can be saved as PNG, as raw data or as assembler source.

The Characters button shows the character sets the screen uses (also several, when a game switches them further down) in the colours of the screen and marks the characters in use. Any character set in memory or in the ROM can be viewed too, and saved as PNG, raw data, a .64c file or assembler source.

The Music button records what the SID plays as a WAV file, or finds the music routine of the running program and saves the tune as a SID file for SID players.

Built-in ROMs: the free MEGA65 Open ROMs (LGPL 3). They run most games, but their BASIC is incomplete. Without a 1541 ROM a virtual drive loads the disks; it also runs drive code that programs upload, so most fast loaders work. For full compatibility load the original C64 ROMs (KERNAL, BASIC, character ROM) and the 1541 DOS ROM once; they are stored only in this browser.
