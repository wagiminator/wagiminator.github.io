C64 Cartridge Builder

Put one or more C64 programs on a Magic Desk cartridge for the 64k/256k or 512k cartridge. Several programs get a selection menu; a single program starts right away. The result is a BIN file for the EPROM and a CRT file for emulators.

1 EPROM size

2 Programs

Drag entries to change their order or move them to another menu. Keys show which key starts the program in the menu.

Menu preview

Close to what the C64 shows, drawn without the C64 character set and without the waving. Programs start with the key in front of their name; F-keys or RETURN switch between menus.

3 Cartridge image

    Burn the BIN file to the EPROM with your programmer. The CRT file runs in VICE and other emulators (Magic Desk type).
