Game Console Flasher

Put a new game on your CH32V003 Mini Game Console: choose a game, connect a WCH-LinkE to the PROG header of the console and flash it straight from the browser.

This browser cannot access USB devices. Open this page in Chrome, Edge or Opera on a desktop computer.

Take out the battery or switch the console off while it is powered by the WCH-LinkE.

Setup and link mode

The WCH-Link must be in RISC-V mode: its blue LED is off. If the blue LED is on, connect it and choose Switch to RISC-V mode, or hold the ModeS button while plugging it in.

Windows: install the WinUSB driver for the WCH-Link's debug interface (not the serial port) with Zadig.

Linux: allow access to the device:

echo 'SUBSYSTEM=="usb", ATTR{idVendor}=="1a86", ATTR{idProduct}=="8010", MODE="666"' | sudo tee /etc/udev/rules.d/99-WCH-LinkE.rules
echo 'SUBSYSTEM=="usb", ATTR{idVendor}=="1a86", ATTR{idProduct}=="8012", MODE="666"' | sudo tee -a /etc/udev/rules.d/99-WCH-LinkE.rules
sudo udevadm control --reload-rules

For other WCH chips, erasing, unlocking or unbricking use the WCH RISC-V Programmer.

3. Flash

The game replaces the program on the console. It is downloaded from the game console repository, written and verified.
