Serial Terminal

Talk to a microcontroller through a USB-to-serial converter (CH340, CP210x, FTDI, PL2303) or a USB CDC device, straight from the browser.

This browser cannot access serial ports. Open this page in Chrome, Edge or Opera on a desktop computer.

Terminal

RX 0 · TX 0

Connection

Not connected

Choose the settings, then connect and select the serial port.

Display

Help

Received line breaks (CR, LF or CR+LF) start a new line, other control characters are shown by name (e.g. <BEL>) and ANSI color codes are removed. Changing a setting while connected reopens the port.

Drivers: CH340, CP210x, FTDI and CDC devices usually work without installing anything on current Windows, macOS and Linux versions; otherwise install the manufacturer's driver. On Linux the user must be in the dialout group.

A port can only be used by one program at a time: close other terminals and serial monitors first.

Serial Terminal by wagiminator. Uses the Web Serial API; nothing is sent anywhere but to the serial port.
