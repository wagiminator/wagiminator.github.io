XGecu Memory Programmer

Read, write and verify EPROMs, EEPROMs and flash memory (parallel, SPI, I2C, Microwire, DataFlash, FWH/LPC) with an XGecu TL866A, TL866CS, TL866II+ or T48. Choose the chip from over 22,000 names, or let the app detect an SPI flash by itself.

This browser cannot access USB devices. Open this page in Chrome, Edge or Opera on a desktop computer.

    Write and verify

      Write erases an electrically erasable chip first (code memory), writes the file (rounded up to whole blocks and padded with the blank value) and verifies it. UV-EPROMs must be blank. Verify compares the chip with the file.

      Read and erase

      Reads the whole memory and saves it as a BIN file.

      Checks that every byte has the blank value (0xFF on most chips).

      Erases an electrically erasable chip (EEPROM, flash). UV-EPROMs are erased with UV light.

      Inserting the chip

      Pin 1 of the ZIF socket is at the top left, next to the lever. A DIP chip sits at the bottom of the socket with its notch and pin 1 pointing up towards the lever, as Xgpro shows it: a DIP8 uses the lowest four rows, a DIP28 the lowest 14 rows, a DIP40 the whole socket. Close the lever before any action.

      Chips in other packages need an adapter. SOIC, SOP, TSSOP, WSON and similar packages go into a package-to-DIP adapter (or a test clip), which is inserted like a DIP chip of the same pin count. PLCC chips need a PLCC to DIP adapter. TSOP32/40/48, SOP44 and SOP56 chips need the matching XGecu adapter. The TL866A/CS and TL866II+ check that a TSOP48, SOP44 or SOP56 adapter is there.

      A chip inserted the wrong way round can be damaged. The programmer switches off and reports overcurrent if it detects a short.

      More options

      Windows: the TL866II+ and T48 work with the XGecu driver that comes with Xgpro. The TL866A/CS needs the WinUSB driver, which you can install with Zadig (Xgpro then no longer finds it).

      Linux: allow access to the programmer:

      echo 'SUBSYSTEM=="usb", ATTR{idVendor}=="04d8", ATTR{idProduct}=="e11c", MODE="666"' | sudo tee /etc/udev/rules.d/99-tinypro.rules
echo 'SUBSYSTEM=="usb", ATTR{idVendor}=="a466", ATTR{idProduct}=="0a53", MODE="666"' | sudo tee -a /etc/udev/rules.d/99-tinypro.rules
sudo udevadm control --reload-rules

      The T56 is not supported here (it needs FPGA algorithm files); use tinypro.py or minipro for it.
