    Packed data for your own program

    Only the packed bytes, without unpacker and load address, for the unpacking routines that come with the packers.

    • like tscrunch -p: one byte zero run length first; for decrunch.asm
    • like exomizer raw (protocol 39), read forward
    • like exomizer raw -b, read from the end; for exodecrunch.s

    Good to know

    • The packed program has a BASIC line 10 SYS2061. It moves the packed data and the unpacker to the top of the memory, unpacks the program to its own address and starts it. A BASIC program that is only a SYS line is started at the SYS address directly.
    • While it unpacks, the whole memory is RAM; the unpacker sits at $FC00. So programs can reach up to $FBFF, including $A000–$FFFF under the ROMs.
    • Exomizer and TSCrunch are packers by Magnus Lind and Antonio Savona. The packed data here has their formats; the packing and the unpackers in the self-extracting file are written for this app. Every packed program is unpacked once on an emulated 6502 before you can save it, to check it.
    • The tape image starts loading with LOAD (or Shift+Run/Stop): the loader is in the tape header and starts by itself. It reads the program at about 400 bytes per second with the screen off.
