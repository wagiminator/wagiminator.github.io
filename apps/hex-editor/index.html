      Good to know

      • Formats: Intel HEX and S-records with all address records, UF2 (also with family), ELF (32 and 64 bit, Arm, RISC-V, AVR, …) and anything else as binary. The format is detected from the content; Read as Binary shows a HEX file as text bytes.
      • ELF: the image shows the loadable segments at their load addresses, as objcopy writes them for the programmer; File shows the ELF file itself. Both edit the same bytes, and ELF (changed) saves the file with the changes. Click a symbol to go to it.
      • Saving: only the ticked regions are saved. Binary fills the gaps between regions; a binary starts at the lowest address saved.
      • Editing: click a byte, then type hex digits (or text in the right column; Tab switches). Shift with arrows or mouse selects; Ctrl+Z and Ctrl+Y undo and redo; Ctrl+A selects everything; Ctrl+C copies the selection as hex. Changed bytes are marked.
      • Search: hex bytes with ?? for any byte, or text; Enter finds the next one. Go to takes an address in hex (0x0800 0000, 8000000) or a symbol name.
      • Checksums cover the selection, or all ticked regions when only one byte is selected; gaps are left out.
